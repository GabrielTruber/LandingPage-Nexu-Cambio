# LandingPage Nexo Câmbio

Três propostas de landing page one-page (com scroll reveal) para apresentação da Nexo Câmbio a clientes.

## Layouts

- **[Institucional](layouts/institucional.html)** — azul-marinho e dourado, tom de corretora tradicional e confiável.
- **[Fintech](layouts/fintech.html)** — dark mode, ticker de cotações ao vivo, visual de produto tech.
- **[Editorial](layouts/editorial.html)** — minimalista, tipografia serifada, grid de linhas finas.

Abra `index.html` para navegar entre os três.

## Tecnologia

HTML/CSS/JS puros, sem dependências de build. Scroll reveal implementado com `IntersectionObserver`, respeitando `prefers-reduced-motion`. Cada layout suporta tema claro e escuro.
